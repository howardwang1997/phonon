# 计划:把 T_el 条件化长程项训练进 MLIP,准确复现含 smearing 的声子谱

**分支** `smearing-kink-ml` · **建档** 2026-07-04 · **状态** 规划(待启动 Phase 0)

---

## 0. 目标与现状差距

**目标**:在 MLIP 里加入一个**电子温度 T_el(=degauss×157888 K)条件化、可微、可出力的长程项**,使它准确复现 smearing 依赖的声子谱——具体以 graphene 的 Kohn kink_K(T_el) 趋势为验收指标(目标 MAE < 1,力争 < 0.5;当前 1.7)。

**现状**:`FriedelMACECalculator` = 蒸馏 backbone 上**手工拟合的 2 参数解析 Friedel 模板**(D0 固定 + B、κ 随 T_el)。6×6 上 fit MAE 1.7 / few-shot 0.87,**中段 T_el 系统性高估**。

**四个缺口**:
1. **超胞收敛**:6×6 最大对距 ~7.4 Å < Friedel 尾 >7–8 Å → 尾巴很可能被截断(疑为中段误差主因)。
2. **表达力**:2 参数太刚 → 加第 3 参数(随 T_el 的波长/相位漂移 δk),或让 D0 随 T_el 轻微插值。
3. **训练化**:B/κ/δk(T_el) 从手工拟合 → 在多 smearing 数据上学习(小网络/样条)。
4. **(路线图)力场级**:离平衡出对力 → 需热扰动力数据。

**推荐架构**:短程 MACE backbone(单一参考 smearing 蒸馏,主谱,T_el-agnostic)+ **T_el 条件化长程 head**(物理参数化阻尼-Friedel 核,D0 从最锐 smearing DFT 取,B/κ/δk 由样条/小网随 T_el 输出)。= 现有 calculator 的训练化升级。

## 4. 论文路线图(future work,本期不跑,写进发表规划)

**R1 家族通用长程项**:引入材料描述子条件化(费米波长/带填充等),用 D4 多材料数据训练**一个跨家族的长程项**;验收 = 各 CDW 材料 soft-mode(T_el) 熔化曲线 + graphene kink 同一模型复现。预计 +3–5 天/材料。

**R2 力场级(有限温 MD/SSCHA)**:加 D3 热扰动力训练,长程项在离平衡出对力 → 支撑有限温 MD 与 (L) 晶格通道;可闭合"real-T 端到端"(电子 T = 晶格 T 自洽 + 非谐)。预计 +1–2 周 DFT。这是把图 A(smearing/DFT)与图 B(温度/MLIP)统一到**同一引擎、同标度**的关键,也是论文里"含温度声子谱"那一问的严格收尾。

**论文叙事定位**:短程 MLIP 因截断结构性无法复现 Kohn 反常 → 提出物理参数化的 T_el 条件化长程项 → graphene 定量验证(Part 第一版)→ 家族通用(R1)+ 力场级有限温(R2)→ "近 DFT 精度 + MLIP 速度地准确模拟含 smearing/含温度的声子谱"。
