# 计划:把 T_el 条件化长程项训练进 MLIP,准确复现含 smearing 的声子谱

**分支** `smearing-kink-ml` · **建档** 2026-07-04 · **状态** 规划(待启动 Phase 0)

---

## 0. 目标与现状差距

**目标**:在 MLIP 里加入一个**电子温度 T_el(=degauss×157888 K)条件化、可微、可出力的长程项**,使它准确复现 smearing 依赖的声子谱——具体以 graphene 的 Kohn kink_K(T_el) 趋势为验收指标(目标 MAE < 1,力争 < 0.5;当前 1.7)。

**现状**:`FriedelMACECalculator` = 蒸馏 backbone 上**手工拟合的 2 参数解析 Friedel 模板**(D0 固定 + B、κ 随 T_el)。6×6 上 fit MAE 1.7 / few-shot 0.87,**中段 T_el 系统性高估**。

**四个缺口**:
1. **超胞收敛**:6×6 最大对距 ~7.4 Å < Friedel 尾 >7–8 Å → 尾巴很可能被截断(疑为中段误差主因)。
2. **表达力**:2 参数太刚 → 加第 3 参数(随 T_el 的波长/相位漂移 δk),或让 D0 随 T_el 轻微插值。
3. **训练化**:B/κ/δk(T_el) 从手工拟合 → 在多 smearing 数据上学习(小网络/样条)。
4. **(路线图)力场级**:离平衡出对力 → 需热扰动力数据。

**推荐架构**:短程 MACE backbone(单一参考 smearing 蒸馏,主谱,T_el-agnostic)+ **T_el 条件化长程 head**(物理参数化阻尼-Friedel 核,D0 从最锐 smearing DFT 取,B/κ/δk 由样条/小网随 T_el 输出)。= 现有 calculator 的训练化升级。

## 2b. Phase-1 执行顺序(只做声子谱;明确"先跑什么、跑完再跑什么")

四步**严格串行**(每步依赖上一步的产物),每步内部三机并行。↓

### ▶ STEP 1(进行中):P0 超胞收敛 —— 定生产超胞 N*
> 目的:声子谱的 Kohn 反常是长程的,先确认多大超胞能收敛 kink,避免尾巴被截断。

| 机器 | 跑什么 | 顺序 |
|---|---|---|
| Box A | graphene **10×10** × degauss{0.005,0.02,0.08}(host-RAM 已修) | 三档顺序跑 |
| Box B | graphene **8×8** ×3 → 再 **6×6** ×3(同一 k 密度 eff~48) | 8×8 先,6×6 后 |
| 2060 | **短程 backbone 蒸馏**(dg0.080 参考,与 DFT 并行,独立) | 一次 |

**判据 & 岔路**:提取各尺寸 kink_K(T_el),看 6×6→8×8→10×10 是否收敛(Δkink<0.3)。
- 若 8×8 ≈ 6×6 → 收敛,**N\*=8×8**(生产便宜,10×10 可不必等)。
- 若 8×8 ≠ 6×6 → 需 10×10 定平台,**N\*=10×10**。
产物:`results/smearing_kink/supercell_conv.csv` + 收敛图 → **锁定 N\***。

### ▶ STEP 2:P1 密集 smearing 扫描(D2)—— 训练主数据
> 依赖 STEP 1 锁定的 N*。这是长程项的训练集。

| 机器 | 跑什么 |
|---|---|
| Box A | N\* 上 degauss 低段 {0.002,0.003,0.004,0.005,0.006,0.007} 冻结声子 → fc₂ |
| Box B | N\* 上 degauss 高段 {0.010,0.015,0.020,0.030,0.040,0.060,0.080} 冻结声子 → fc₂ |
| 2060 | 等数据(STEP 1 的 backbone 此时已就绪) |

产物:`results/sc_conv/`(或 `vq_kinkN*`)下 ~13 档 fc₂(T_el) yaml。数据一出即 rsync 2060。

### ▶ STEP 3:P2 长程 head 训练(2060 / 本地)
> 依赖 STEP 2 的 fc₂(T_el) + STEP 1 的 backbone。

- 升级 `friedel_module`:2 参 → **3 参(B, κ, 相位/波长漂移 δk)随 T_el**,D0 取最锐 smearing。
- 在 D2 上**留出交叉验证**拟合 B(T_el)/κ(T_el)/δk(T_el)(样条或小网络)。
- 包进 `friedel_calc` 作 T_el 条件化可出力项。
产物:训练好的长程项 + 留出 kink_K MAE(目标 <1,力争 <0.5)。

### ▶ STEP 4:P3 验证 + 部署(2060 / 本地)
> 依赖 STEP 3 的项。

- backbone + 长程项组成 calculator,在**留出 smearing** 上跑全色散 → kink_K(T_el) vs DFT。
- 声子网格无关性检查(grid-independence)。
产物:**能准确复现含 smearing 声子谱的 MLIP** + 验证图 + 写入周报/论文 Part。

### 每台机器的串行顺序(一句话版)
- **Box A**:P0 10×10 → P1 低 degauss 段 → 待命。
- **Box B**:P0 8×8→6×6 → P1 高 degauss 段 → 待命。
- **2060**:backbone 蒸馏 →(等 D2)→ P2 head 训练 → P3 验证。
- **关键 gate**:STEP1 定 N\* 之前不开 STEP2;D2 齐之前不做 STEP3 终版(可边出边拟)。

## 4. 论文路线图(future work,本期不跑,写进发表规划)

**R1 家族通用长程项**:引入材料描述子条件化(费米波长/带填充等),用 D4 多材料数据训练**一个跨家族的长程项**;验收 = 各 CDW 材料 soft-mode(T_el) 熔化曲线 + graphene kink 同一模型复现。预计 +3–5 天/材料。

**R2 力场级(有限温 MD/SSCHA)**:加 D3 热扰动力训练,长程项在离平衡出对力 → 支撑有限温 MD 与 (L) 晶格通道;可闭合"real-T 端到端"(电子 T = 晶格 T 自洽 + 非谐)。预计 +1–2 周 DFT。这是把图 A(smearing/DFT)与图 B(温度/MLIP)统一到**同一引擎、同标度**的关键,也是论文里"含温度声子谱"那一问的严格收尾。

**论文叙事定位**:短程 MLIP 因截断结构性无法复现 Kohn 反常 → 提出物理参数化的 T_el 条件化长程项 → graphene 定量验证(Part 第一版)→ 家族通用(R1)+ 力场级有限温(R2)→ "近 DFT 精度 + MLIP 速度地准确模拟含 smearing/含温度的声子谱"。
