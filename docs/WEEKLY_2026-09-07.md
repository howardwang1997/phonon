## 2. R2B tagged-pair 曲率参考

部署热 Hessian 是 SSCHA 自由能 Hessian，其驻点条件即热平均局部曲率。R2B 直接测该对象：12 个分层冻结储备种子 × `u_i ± 0.04 Å·P`，P 为部署 S0@450 短程 Hessian 的 K-A′ 本征位移（Γ 本征空间簇，本征残差 4e-16）。投影曲率经 q6 算子力扣除后加共享 Π(K) 得绝对 K 参考。合成端到端（以 `−(short_S0+q6)·u` 模拟标签）：全部门限通过，曲率 K 精确到 `5.5e-12 cm⁻¹`，形态 RMSE `0.41/max 0.89 cm⁻¹`。

| 量 | 值 |
|---|---|
| λ_short,DFT | `6.51630 eV/Å²/amu`（m·λ = 78.269 eV/Å²） |
| ω_full,DFT（共享 Π 组合） | **`1300.209 cm⁻¹`** |
| 部署 S0 / R2AO | `1269.796 / 1266.285 cm⁻¹` |
| 绝对差 | **`+30.41 cm⁻¹`（+2.4%），统计误差 ±1.5** |
| 逐种子曲率 | `−75.99 … −80.12 eV/Å²`，std 1.08 → 系统性 |
| split-half（6/6） | `1297.17 / 1303.24`，spread `6.08 cm⁻¹`（门限 5，边缘） |

交叉读数：不做 q6 拆解的 DFT 总曲率给 `ω_total ≈ 1301.2` vs 部署 finite_q6 对象 `1270.4`——同样的 ~31 cm⁻¹，说明偏差在 Born–Oppenheimer 总体系内，与拆解方式无关；组合拟合自身的 K（`1301.74`）在真实 DFT 上独立佐证曲率参考（差 1.5 cm⁻¹）。

**判定总结**：(i) 组合机制验证通过（存储矩阵逐位回放；估计器合成精确、真实 DFT 上被独立拟合佐证 1.5 cm⁻¹）；(ii) **频谱形态主张在 450 K 确认**——Kohn cusp 深度与线形对独立 DFT 一致到 ~1 cm⁻¹ / ~4%；(iii) **绝对频率主张在 450 K 未确认**——部署 S0 的 K-A′ 系统性偏软 +30.4±1.5 cm⁻¹（2.4%）。部署组合在 450 K 的精度包络：**形态 ~1 cm⁻¹，绝对 K ~30 cm⁻¹**。

## 4. 绝对频率再标定（完成，全部门限通过）

设计（执行前冻结）：偏差是 K 通道的系统标量（逐种子 std 仅 1.08 eV/Å²），标定常数 Δ(m·λ) = −⟨曲率⟩_(前 6 种子) − m·λ_short(部署) = **+3.1033 eV/Å²**（≈ +70262 cm⁻²），标定种子 69/118/126/197/31/92，留出 14/10/227/120/215/100。

**v1 秩一实空间形式失败（如实记录）**：`short_fc + Δ·P⊗P/‖P‖²` 的 P 是超胞 Γ 本征矢 = 纯 K 星 Bloch 态，实空间 Fourier 宽度 ~1/L ≈ 0.17 (2π/a) **大于整个 ±0.04 密集窗口**——K 星两个成员各吸收约一半位移，全窗口抬升 +13.2，修正后 K 仍差 16.26 cm⁻¹。诊断副产品即真相：DFT 拟合 − 部署在窗口内是**均匀的 ~+31.9 cm⁻¹**（RMS 偏离常数仅 0.63——与 K 参照形态 RMSE 0.63 同源），偏软是**支均匀的 A′ 分支刚度整体偏移**，不是 K 局部亏损。

**v2 修正形式（证据驱动改轨，门限不变）**：把 Δ(m·λ) 以均匀模式投影方式加在响应通道上——`apply_mode_projected_correction(short 序列, …, Π + ΔΠ_calib)`，与部署组合走同一代码路径（`dynamical_sequence → track_branch → apply_mode_projected_correction`）。不修改任何实空间 fc 对象 → Γ/M 与非 A′ 分支**构造上不受影响**，修正范围即该 K 窗口 A′ 组合。

| 门限 | 值 | 阈值 | 判定 |
|---|---|---|---|
| 主判据：\|K−K_ref(12 种子)\| | **3.042 cm⁻¹** | ≤ 5 | ✓ |
| 留出一致性：\|K−K_ref(留出 6)\| | 6.076 cm⁻¹ | = 噪声底 6.076（对照读数） | ✓ 到统计地板 |
| cusp 深度误差 d=0.003 / d=0.025 | **2.11% / 2.08%** | ≤ 15% | ✓（优于部署原值 2.95%/3.75%） |
| 形态不劣化（非 K 参照 RMSE vs DFT 拟合） | **31.43 → 4.34 cm⁻¹** | 不劣化 | ✓ |

修正后 K = **1297.168 cm⁻¹**（= 标定半区参考，构造使然）；主判据的 3.04 cm⁻¹ 正是"12 种子参考 − 标定半区参考"的半区统计涨落——修正把绝对频率误差从 30.4 压到参考自身的种子噪声水平。留出残差 6.076 恰等于 split-half 噪声底（修正落在标定半区参考上，留出半区与 12 种子均值本来就差 6.08）：**修正的泛化受限于参考的统计，而非修正本身**。未修正回放仍 0.0 cm⁻¹。
