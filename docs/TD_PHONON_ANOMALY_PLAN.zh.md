# 二维材料中含温声子色散与色散异常的 MLIP 计算方案

**目标。** 用基础/FC 蒸馏 MLIP 计算二维材料的**含温声子色散 ω(q, T)**（即"Level 3"非谐区间），
**定位色散曲线上的斜率突变 / 跃变点（"跳点"），并追踪它们随温度的移动**，再把这些异常与问题真正
关心的电子–声子物理联系起来。

---

## 0. 把这个物理现象叫准确

题目所描述的——*二维晶格在实空间是平整的，但其振动模式在声子能带图上会出现斜率的突变和跃变，
其根源在于电子气与离子实之间的相互作用，并可能与某种输运窗口相关*——用标准语言来说，就是：

- **科恩反常（Kohn anomaly）。** 传导电子对离子运动有屏蔽作用。当声子波矢 **q 连接费米面上的两点
  时**（即 **q\* ≈ 2k_F**，费米面**嵌套 / nesting**），这种屏蔽（来自电子–声子耦合的声子自能）会出现
  **奇异性**，于是 ω(q) 在 q\* 处产生一个**尖点 / 折点 / 局部软化**——色散曲线上的非解析特征。
- **维度效应。** 维度越低，奇异性越尖锐：一维下它发散并驱动 Peierls / 电荷密度波（CDW）畸变；
  二维下它表现为**尖锐的折点**（石墨烯在 Γ 点的 E₂g、K 点的 A₁′；单层 NbSe₂ / TaS₂ 凝聚成 CDW 的
  软模异常）。
- **输运联系（这是要验证的假设，而非前提）。** q\* 标记了费米面的某个特征，因此该异常是"晶格在哪里
  与电子强耦合"的**指纹**——这正是"弹道输运电导窗口"直觉的来源。**但声子异常只是该费米面几何的
  定位器 / 信号，它本身并不是电子电导率。** 要建立这个联系，必须借助电子结构（见下），并且这是一个
  需要被*证明*的结果，而不是被假定的前提。

所以具体的研究路线是：**ω(q, T) → 检测折点 q\*(T) → 检验 q\* ≈ 2k_F → 关联到输运。**

---

## 1. 诚实的边界——MLIP 能算什么、不能算什么（先读这一节，它决定全部方案）

MLIP（MACE-MP、MatterSim……）学的是**玻恩–奥本海默势能面** E({R})——在电子处于*基态*的前提下，把
电子积分掉之后的能量与力。它的力常数（fc₂、fc₃……）*隐式地*包含电子–声子效应，但**仅当训练用的
DFT 数据捕捉到了它、且模型表达能力足以重现由此产生的非解析性时**才成立。由此引出两条硬性限制，
而它们恰好就是本仓库主论文记录的失效模式：

1. **科恩反常是 fc₂(q) 中一个尖锐、近乎非解析的折点；而 MLIP 会系统性地*抹平/软化*曲率**——这正是
   §2.1 的核心发现（基础 MLIP 低估曲率，把 ω_max 软化约 10–28%）。一个局域的 2k_F 尖点，恰恰是最
   容易被**抹掉**的特征。⇒ 裸的基础 MLIP 很可能*错过或模糊*该异常；**FC 蒸馏方案（从公开 DFPT 取
   fc₂，§2.2）很可能是恢复它的*必要*手段**——即便如此，任何平滑插值器要重现一个完美尖点都很难。
   *（如果蒸馏之后 MLIP 仍无法分辨它，这本身就是一个干净、可发表的负面结果——"MLIP 漏掉了科恩
   反常"——与 §2.1 完全自洽。）*

2. **该异常的*电子*温度依赖不在 MLIP 里。** 升温使费米–狄拉克占据展宽 → 费米面模糊 → 2k_F 奇异性
   变宽、折点被抹平。这是一个**电子**效应。而 BO 势能面（因而 MLIP）是在电子*基态*下求得的，**不带
   任何电子温度展宽**。

### 由此被迫做的温度分解（本方案的思想核心）
把温度依赖拆成两个通道，且绝不混为一谈：

| 通道 | 机制 | MLIP 能看到吗？ | 如何获得 |
|---|---|---|---|
| **(L) 晶格 / 非谐通道** | 声子占据、热膨胀、声子–声子重整化 | **能**（全在 BO 势能面里） | MLIP + SSCHA/TDEP（Level 3）——便宜 |
| **(E) 电子通道** | 2k_F 电子–声子异常的费米面展宽 | **不能**（基态势能面） | 带电子展宽 T_el 的 DFPT（或 EPW）——DFT，昂贵 |

**操作原则：** 用 MLIP 算 (L) 通道、并廉价地扫描大量温度与大超胞；用**有针对性的、带电子展宽的
DFPT** 作为 (E) 通道的参考、并确认 q\* ≈ 2k_F。每一个报告出来的温度趋势都必须标明它来自哪个通道。
*（对于 CDW / 软模材料，两个通道是耦合的——非谐稳定化 (L) 与电子异常 (E) 共同决定相变——所以两者
都要建模，而对来源的诚实标注在这里最重要。）*

## 2. Level-3 含温声子的方法（MLIP / (L) 通道的主力）

| 方案 | 给出什么 | 何时用 | 工具 |
|---|---|---|---|
| **QHA**（准谐近似） | 仅来自热膨胀的频移 | 廉价基线 / 检查 | phonopy（仓库已有） |
| **TDEP**（含温有效势） | 有效 fc₂(T) → ω(q,T)；fc₃(T) → 线宽 | 默认主力、稳健 | **hiPhive**（与 ASE+phonopy 原生集成）或 TDEP |
| **SSCHA**（随机自洽简谐） | 自由能海森矩阵频率；可处理不稳定性 | 强非谐 / 接近 CDW | python-sscha |

**建议：** 以 **hiPhive-TDEP + FC 蒸馏 MLIP** 作为主力（与 ASE/phonopy 集成干净，可在细 q 网格上给出
fc₂(T) 以及用于线宽的 fc₃）；对 CDW / 软模情形用 **SSCHA**（此时 TDEP 的微扰基础变弱）。两者都只需要
热采样超胞上的力——成千上万次求值，在 DFT 中不可行，但用 MLIP 极其廉价。*这种廉价正是在这里使用
MLIP 的全部理由。*

## 3. 材料选择（分层、验证优先）

1. **石墨烯** —— Γ 点（E₂g）与 K 点（A₁′）的科恩反常是教科书级的尖锐、且有充分实验测量；半金属 →
   电子–声子的干净检验，也是验证异常定位器与"MLIP 是否抹平尖点"问题的已知靶标。
2. **单层 MoS₂** —— 有带隙、异常弱或没有 → 负对照（定位器应当*什么都找不到*）。
3. **单层 NbSe₂（或 TaS₂）** —— 强科恩反常 / 软模凝聚成 CDW → 最戏剧化的情形，也是最清晰的"输运
   窗口"候选；属于 SSCHA 领域，且 (E) 通道在这里必不可少。

## 4. 流程（基于仓库现有基础设施，具体化）

```
对每个材料：
  1. 弛豫（ASE + FC 蒸馏 MLIP）                                  # structures.relax
  2. 对每个温度 T（如 10–600 K）：
       a. 正则采样：NVT/Langevin MD 或 SSCHA 系综（MLIP 算力）
       b. 拟合有效 fc2(T)[+ fc3(T)]                              # hiPhive TDEP（或 SSCHA 海森矩阵）
  3. 在细 q 路径上求色散 ω(q,T)                                  # phonopy 从 fc2(T)，复用 phonons.py
  4. 异常检测（新增）：
       v(q)   = dω/dq            每支声子（细路径上有限差分）       # 群速度
       折点    = |d²ω/dq²| 的峰 与 v(q) 的不连续                  # 稳健做法：平滑求导 + 阈值
       输出 q*(T)、折点强度 Δ(斜率)、声子支索引
  5. 温度追踪：q*(T) 与折点强度随 T  →  色散-异常图谱
  6. 电子端交叉验证：
       - DFT 费米面 + 2k_F 嵌套矢量（一次 DFT）；检验 q* ≈ 2k_F
       - （更重）带电子展宽 T_el 的 DFPT → MLIP 造不出的 (E) 通道异常
  7. 弹道输运解读：
       - 声子侧：由 ω(q,T) 得群速度 + Landauer 弹道声子电导
       - 电子侧（诚实）：q*(T) 定位费米面特征；*电子*弹道窗口需要电子–声子（EPW）——
         声子异常是信号，不是电导率本身
```

计划中的代码：
- `scripts/td_phonon.py` —— 采样（MD/SSCHA）+ 有效 fc₂(T) 拟合 + 每温度色散。
- `scripts/anomaly_locate.py` —— 群速度 / 曲率折点检测器 → q\*(T)、Δ斜率。
- `scripts/plot_td_dispersion.py` —— 标注异常的 ω(q,T) 叠图；q\*(T) 追踪面板。

## 5. 验证与诚实性检查
- 用 MLIP 在低温重现石墨烯 Γ/K 异常，与 DFPT 对比 → **量化基础 MLIP 把尖点软化了多少、以及 FC 蒸馏
  能否恢复它**（直接延伸 §2.1/§2.2）。
- 从 DFT 费米面确认 q\* ≈ 2k_F（异常假设）。
- 在每张图 / 每个结论里保持 (L) 与 (E) 通道分离；绝不把电子展宽的物理归到 MLIP-only 的结果上。
- 收敛性：超胞尺寸、q 路径密度、MD 时长 / 系综大小、电子展宽（DFT 端）。

## 6. 里程碑
- **M1** —— 石墨烯：用 FC 蒸馏 MLIP 做 hiPhive-TDEP 的 fc₂(T)；ω(q,T)；异常定位器跑通；在某一温度
  与 DFPT（及已知的石墨烯科恩反常）对照验证。
- **M2** —— q\*(T) 追踪 + 折点强度图谱；用 DFT 费米面做 2k_F 交叉检验。
- **M3** —— 单层 NbSe₂（SSCHA）：强异常 / 软模的随温演化。
- **M4** —— 弹道输运解读 + (L)/(E) 通道来源的论述写作。

## 7. 风险 / 开放问题
- **首要风险：** MLIP 抹平了我们要找的那个尖点。缓解：FC 蒸馏 + DFPT 验证；若仍失败，则作为负面
  结果报告（它加强而非削弱主论文）。
- TDEP 的微扰基础在接近 CDW 不稳定时失效 → 在那里改用 SSCHA。
- "弹道输运窗口"这个联系（q\* ↔ 某个电子输运特征）是**待检验的假设**，不是前提——它需要电子结构 /
  电子–声子，而这正是 MLIP 不提供的。
- **算力：** 认真的超胞 MD / SSCHA 需要 GPU 机器（目前已从 tailnet 下线）；小石墨烯胞可本地完成。
  DFPT + 费米面验证需要强 FP64（租用）硬件。

## 8. 依赖
- Python：`hiphive`、`phonopy`、`phono3py`、`ase`、（CDW 情形用 `python-sscha`）、仓库的 MLIP 计算器
  （`phonon-mace` 环境 / FC 蒸馏模型）。
- DFT（仅验证用）：Quantum ESPRESSO（带电子展宽的 DFPT + 费米面；可选 `epw`）。

---

### 一句话总结
用 MLIP（FC 蒸馏，以抵消 §2.1 的软化）+ TDEP/SSCHA，廉价地拿到跨温度的**晶格-非谐** ω(q,T)，
构建稳健的**折点 / 科恩反常定位器**提取 q\*(T)，再用**带电子展宽的 DFPT**（MLIP 结构上做不到的部分）
交叉验证 q\* ≈ 2k_F 与异常的*电子*温度展宽——并把弹道输运联系作为一个有诚实 (L)/(E) 来源标注的、
*待检验*的假设来报告，而不是一个假定。
