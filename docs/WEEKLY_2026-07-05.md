# 周报 · 2026-07-05 — 含 smearing 声子谱 via MLIP:家族级 + 通用长程项(R1)

**分支** `smearing-kink-ml` · **主题** 把"短程 MLIP + 解析长程项 = 准确含 smearing 声子谱"从 graphene 推广到整个 CDW 家族,并做家族通用化(R1)

---

## TL;DR
上周(07-04)在 **graphene** 上证明了"短程 MLIP backbone + T_el 条件化长程项 → 准确含 smearing 声子谱"(kink MAE 0.31 cm⁻¹)。本周把它**做成家族级**:
- **5 个 CDW 材料**用真实蒸馏 MACE backbone + 长程项部署,复现 DFT soft-mode(T_el) 熔化,**MAE 0.011–0.16 THz**(VSe₂ 0.71 例外,见下)。
- **R1 家族通用化**:振幅 B(T_el) 在 T½ 重标下坍缩成一条通用曲线;few-shot(2 档)可迁移到新材料;DOS(Ef) 是 T½ 的正确描述子方向;D0 波形同型内可共享。

**结论:"含 smearing 声子谱 via MLIP"现在是家族级的,不再是 graphene 单点。**

## 2. R1 — 家族通用长程项

目标:一个描述子条件化的长程项,对新材料**不用重跑熔化曲线**就能给出含 smearing 声子谱。

- **坍缩**(`r1_B_collapse.png`):5 材料的振幅 B(T_el) 在 **T½ 重标**下坍缩成一条通用曲线(residual 9%)→ 一条通用 B(x) + 每材料一个标量 T½。
- **通用律**:通用 B(x) + T½ + 各自 D0 复现家族熔化,MAE 0.16–0.62 THz(比逐材料拟合松 2–5 倍,但零 B 拟合)。
- **Few-shot**(留一法):通用 B(x) + 1 档 anchor → TaSe₂ MAE 0.07、NbSe₂ 0.25;NbS₂ 1.1(家族反常成员,无体相 CDW)。→ **对新材料 2 档 DFT 即可迁移。**
- **描述子**(`r1_dos_Thalf.png`):测了 χ(q_CDW)、软模深度、q_CDW、**DOS(Ef)** 对 T½ 的相关性。**DOS(Ef) 最好**(r=+0.48 全部 / +0.65 仅 2H,物理方向对:费米面态密度↑→CDW 越顽固→T½↑),但 n=5 太少 + 跨型敏感 → 零样本律需更多材料。
- **D0 共享**(`r1_D0_envelopes.png`):同型(2H,q_CDW=1/3)的费米面波形 D0 包络**形状相似**(共同振荡结构),振幅材料特定 → D0 形状可同型内共享。

**R1 一句话**:家族通用**形状**成立(B(x) 通用、D0 同型共享);**尺度 T½** 靠 few-shot(现在可用)或 DOS(Ef)(方向对,需更多材料)。

## 3. 附带发现
- **1T-TiSe₂**(半金属):软模几乎不随 T_el 熔化(−0.59→−0.47)→ 其 CDW 对电子温度**顽固**(与激子/非嵌套起源一致),和其它强熔化的 CDW 形成对比。
- **Gapped 对照**(MoS₂/WSe₂):**DOS(Ef)=0.0000**(半导体,无费米面)→ 无嵌套无 CDW,家族的对照端坐实。
- **EPW λ(T_el)**:VSe₂ 好(2.12–2.24);TiSe₂ λ 物理性发散(半金属 DOS→0)= 结论非 bug。

## 4. 诚实边界 —— 含温度那半还没做
支线核心 = 准确算**两种**声子谱:含 smearing(电子温度)+ 含温度(晶格 T_lat)。
- **含 smearing via MLIP:本周基本收口(家族级)。** ✅
- **含温度 via MLIP:只有 NbSe₂ + graphene 两个点,家族没铺开。** ⚠️ 且谐振蒸馏 backbone 不含非谐,家族 (L)-通道需要**新的非谐 DFT 数据 + 非谐微调 + SSCHA**(每材料 +数天)—— 是新工程,不是收尾。
