## 2. A2 诚实测试:NbS₂ 4×4 — 3×3 抹平了 (L) 软模,但根因是模型双井深度

A2 跑 NbS₂(2H 中 bare 软模最深 −103 cm⁻¹,最强测试)4×4 Path-P → 微调 → SSCHA:

| T_lat | NbS₂ 3×3 SSCHA | NbS₂ 4×4 SSCHA |
|---|---|---|
| 20 K | ~0 | **−264.6 cm⁻¹** |
| 100 K | ~0 | ~0 |
| 200/300 K | ~0 | ~0 |

→ 4×4 暴露了 3×3 抹平的低 T (L) 软模(heal 在 ~100K,NbS₂ 无 CDW)。

**但诊断(关键诚实点)**:DFT fc₂ **bare** 软模 3×3=−63 / 4×4=−69 cm⁻¹ **相近** → 3×3 vs 4×4 的 SSCHA 巨差**不是 DFT 收敛**,而是 **Path-P 微调模型的双井深度**:4×4 模型学了更深双井 → SSCHA 自由能 Hessian 软模更深。

**含义(写文章须交代)**:
1. 2H "(L)-惰性"的结论是 **3×3 Path-P 模型层面**的,4×4 模型给出更深软模 → **模型/超胞敏感**。
2. −264 cm⁻¹ 是**模型输出**,不是 DFT 直接测量;**待 DFT 直接验证**(4×4 双井 DFT 扫描 或 DFT-MD-TDEP)才能定真深井 vs 过拟合。
3. 但 1T vs 2H 的**对比仍稳**:1T (L) 软模深 5–8×(−360/−552)且 heal **在 T_CDW**;2H DFT bare 软模浅(−65)且 NbS₂ 4×4 heal 在 100K(无 CDW)。
4. 2H CDW 材料(NbSe₂/TaS₂/TaSe₂)的 3×3 (L)-惰性需 4×4 复核为严谨(future work,V100 DFT ~2–3h/材料)。

A2 达到设计目的:暴露了 (L)-SSCHA 的模型/超胞敏感诚实边界。

# 更新(2026-07-09 晚)— 三项关键修正 + 主线重定向

## ① NbSe₂ NQ=4 EPW 结果:λ=23 = 软模 divergence,非物理值
`results/smearing_kink/nbse2_lambda_nq4.csv`:d0.03 (T_el=4737K) **λ=23.3**,minfreq −1 cm⁻¹。
- 比 NQ=3 的 λ=17 **更高** → NQ4(incommensurate)**没有清掉 divergence**。
- 根因:NbSe₂ 的 Kohn 软模是 Γ–M 上的**宽峰(ridge)**,任何 q-grid 都采到近零模 → λ∝γ/ω² 发散。
- **定性结论稳**:NbSe₂ 强 EPC(软模增强)→ 电子起源背书。**绝对 λ grid-dependent**(报"强耦合 + 软模增强",不报绝对值,~15–25 range vs 物理 ~1.5)。
- d0.04(第二档)killed(同发散,零价值)。

## ② M2(Family EPW)中止:~9 天,divergent λ,低价值
- 4×4 DFPT ~24h/(材料·档) × 8 = **~9 天**。且 λ 会全 divergent(软脊)。
- (E)-起源已由 MLIP (E)-melting(干净,0.011–0.16)+ NbSe₂ NQ4 背书 → 家族 EPW 边际价值低。
- nbs2 DFPT killed;Box A 释放。

## ③ M1(2H 4×4)中止 + A2 重新定性:4×4 是 q-commensurability 混淆,非收敛问题
- **关键认识**:NbSe₂/TaS₂/TaSe₂ 的 CDW q=(1/3,1/3)。**4×4 超胞不能表示 q=(1/3,1/3)**(其网格点是 1/4 的倍数)→ 4×4 fc2 软模在**不同的 q**(非 CDW q)。
- → A2 的 "NbS₂ 4×4 −264 vs 3×3 ~0" 是 **apples-vs-oranges**(不同 q 的软模),不是超胞收敛问题。
- **3×3 (L)-惰性的结论成立**(3×3 表示 q=1/3;4×4 的 −264 是另一个 q 的软模,不证伪 CDW-q 的惰性)。
- 干净的收敛测试 = **6×6**(3 的倍数,表示 q=1/3)。M1 的 4×4 设计 q-confounded → 中止。

## 主线重定向(执行中)
- **A2-clean**:6×6 fc2(NbS₂ Box A + TaSe₂ Box B,~3–7h)——干净的 q=1/3 谐振收敛测试。若 6×6 bare ≈ 3×3 → 收敛,(L)-惰性坐实;若更深 → 扩到 Path-P+SSCHA。
- **M4 B2d 2D = 负结果(killed)**:SSCHA-through-FriedelMACE 给出垃圾(soft-mode −4215 cm⁻¹,n_imag=144 = 全模虚)。根因:Friedel 长程项是**谐振 fc 校正**(为有限位移 fc2 标定),塞进 SSCHA(非谐 PES 采样)后,其线性力 `−Δfc·u` 扰动**整个** PES(全 fc delta D0 有多个负本征值,不只软模)。→ SSCHA-through-FriedelMACE **概念错误**:(E) 谐振项与 (L) 非谐采样器不能直接合。**Phase-1 成立**(b2d_unified_kink:(E) 谐振切片 + (L) backbone SSCHA **分别**算,共享 reduced-T healing 形式)——统一模型在"分轴 + 共享形式"层面有效,**不是** 2D 可部署 SSCHA(与 B2 step-3 负结果一致)。真 2D 部署需非谐 Friedel 项或 T_el-条件化 backbone(future,难)。

## 三大修正(本轮最重要的认识更新)
1. **A2 = q-commensurability 混淆,非收敛问题**:NbSe₂/TaS₂/TaSe₂ CDW q=(1/3,1/3),**4×4 超胞不能表示它**(网格点 1/4 倍数)→ NbS₂ 4×4 −264 是**不同 q 的软模**,与 3×3 q=1/3 比是 apples-vs-oranges。**3×3 (L)-惰性成立**。origin 分流(2H 电子 / 1T 晶格)在 polytype 层 robust(1T 深百倍)。
2. **NbSe₂ EPW λ 本质 divergent**:Kohn 软脊(Γ–M 宽峰)使任何 q-grid 采到近零模 → λ 发散。**incommensurate NQ 清不掉**。只能报"强耦合 + 软模增强"。
3. **统一模型 2D deploy = 负结果**:谐振 Friedel 项与非谐 SSCHA 采样器不兼容。真 2D 部署需非谐 Friedel 项或 T_el-条件化 backbone(future,难)。
