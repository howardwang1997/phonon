# TD-phonon / 科恩反常项目：详细执行计划（数据 · 方法 · 算力 · 风险）

本文件是 [`TD_PHONON_ANOMALY_PLAN.zh.md`](./TD_PHONON_ANOMALY_PLAN.zh.md)（高层方案）的**可执行细化**：把里程碑
M0–M4 拆成具体步骤，每一步给出 **① 实验数据 · ② 方法论（用什么方法解决什么问题）· ③ 算力（(a) 需求量
(b) 类型）· ④ 风险**。最后附**风险登记表**与 **Go/No-Go 决策门**。

> **贯穿全程的核心张力**（决定整个计划的形态）：MLIP 学的是电子基态的 BO 势能面，因此
> **(L) 晶格-非谐**温度通道它能算、且极廉价；而 **(E) 电子**通道（费米面热展宽导致的科恩反常变化）它
> 结构上算不了，必须用 **DFT（DFPT + 电子展宽）** 验证。更糟的是，§2.1 表明基础 MLIP 会**抹平尖锐
> 曲率**——而科恩反常正是这种尖点。所以 **M1 的首要任务就是先证明"MLIP 到底能不能看见这个尖点"**，
> 这是整个数百 GPU-hr 计划的"保险丝"。

## 总览

| 里程碑 | 一句话 | 主算力 | 量级 | 是否阻塞 |
|---|---|---|---|---|
| **M0** 环境与结构 | 装 hiphive/sscha、备结构 | CPU / 2060 | ~1–2 h | 否 |
| **M1** 石墨烯去风险 | MLIP 能否分辨 Γ/K 科恩反常 + 跑通 TDEP | **RTX 2060** | ~3–5 GPU-hr | **Go/No-Go 门 #1** |
| **M2** q\*(T) 追踪 | 全温区跳点图谱 + 2k_F 对照 | 2060 / H20 + 少量 V100 | MLIP ~10 GPU-hr；DFT 见 M1.3 | 否 |
| **M3** NbSe₂ CDW | SSCHA 软模随温演化（最难） | **H20**（+ V100 验证） | MLIP ~10–40；DFT ~200–500 | **Go/No-Go 门 #2** |
| **M4** 弹道输运 + 写作 | 群速度/电导 + (L)/(E) 论述（可选 EPW） | CPU（+ 可选 V100） | 分析 ~0；EPW +100–300 | 否 |

**算力类型速记：** MLIP-小胞（石墨烯/MoS₂）→ **RTX 2060**（8 GB，现唯一在线）；MLIP-大胞（NbSe₂ CDW
超胞 / 锐异常大胞）→ **H20**（需重新上 tailnet）；**任何真 DFT（FP64：DFPT、费米面、EPW）→ V100/A100
租用**（2060 与 H20 的 FP64 都被阉割，不可行）。

## M0 — 环境与结构准备

**① 数据**：晶体结构。石墨烯（ASE `graphene` / MP `mp-48` 衍生 + 真空层）、单层 MoS₂（mp-2815）、
单层 NbSe₂（C2DB / mp 衍生）。无需 DFT。
**② 方法**：解决"工具链就位"。在 2060 的 `phonon` 环境 `pip install hiphive`（TDEP 拟合）；为 M3 预装
`python-sscha`（独立环境，避免与 mace 的 e3nn/torch 冲突——已知 e3nn 0.4.4 vs 0.6.0 坑）。`git pull` 同步
仓库脚本。
**③ 算力**：(a) ~1–2 h；(b) **CPU + RTX 2060**（本地，无需租用）。
**④ 风险**：*低*。唯一坑是 `hiphive`/`sscha` 与 mace 的依赖冲突 → 用独立 conda 环境隔离。

## M1 — 石墨烯去风险（保险丝；Go/No-Go 门 #1）

### M1.1 谐波基线：MLIP 到底能不能看见科恩反常？
**① 数据**：石墨烯结构（M0）；**参考色散**用**已发表的石墨烯 DFPT/非弹性散射数据**（Γ-E₂g≈1600 cm⁻¹、
K-A₁′ 处的尖锐扭折是教科书级、文献充分），先不自己算 DFT。MLIP 用 (a) 基础 MACE-MP、(b) FC-蒸馏
MACE 两个模型。
**② 方法**：解决"MLIP 是否抹平尖点"这一**生死问题**。phonopy 有限位移 + MLIP 力 → 沿 Γ–M–K–Γ 的密集
色散；跑**异常定位器**（群速度 v=dω/dq 的不连续 / |d²ω/dq²| 峰）。对比 基础 vs 蒸馏 vs 文献，量化尖点
被软化了多少、蒸馏能否恢复。
**③ 算力**：(a) ~0.5–1 GPU-hr（石墨烯 1×1 原胞 + ~5×5 超胞有限位移，仅几十个构型）；(b) **RTX 2060**。
**④ 风险**：**最高、且是全局性的**。(i) MLIP 把尖点抹平 → 看不见异常。缓解：先上 FC-蒸馏模型；若蒸馏
模型对碳的覆盖不足，需用石墨烯自身 DFPT fc₂ 做蒸馏靶（见 M1.1b）。(ii) 异常定位器把数值噪声误判为
尖点 → 用平滑求导 + 阈值 + 多超胞收敛校验。

### M1.1b（条件触发）石墨烯 DFPT fc₂ 蒸馏靶
**① 数据**：若 M1.1 中蒸馏模型不够好，则需石墨烯自身的 **DFPT 力常数**作为蒸馏目标（注意：这是"基础
fc₂"，不是"密 k 解析尖点"，所以**便宜**）。
**② 方法**：QE 在中等 k 网格上做石墨烯 fc₂ DFPT → 按 §2.2 蒸馏出石墨烯专用 MLIP。
**③ 算力**：(a) ~20–50 FP64 GPU-hr；(b) **V100 租用**（2 原子胞但 FP64；H20 也偏弱）。*可先用文献力常数
绕过，把此步推后。*
**④ 风险**：*中*。FP64 阻塞；用文献 fc₂ 或公开石墨烯 phonopy 数据先行。

### M1.2 Level-3 TDEP：含温色散 ω(q,T)
**① 数据**：MLIP 自产的热采样快照（无外部数据）。3–4 个温度（100/300/600 K）。
**② 方法**：解决"拿到 (L) 通道含温频率"。NVT/Langevin MD 或随机系综（MLIP 力）→ hiphive 拟合有效
fc₂(T) → ω(q,T)；定位 q\*(T)。
**③ 算力**：(a) ~1–2 GPU-hr（~6×6=72 原子或 8×8≈128 原子超胞 × ~2k 快照 × 4 T ≈ 15–20k 次力评估）；
(b) **RTX 2060**（8 GB 容得下 ≲300 原子的 MACE 推理）。
**④ 风险**：*中*。(i) 8 GB 显存：若超胞偏大 → 退到 6×6 或 CPU 回退（慢）。(ii) TDEP 拟合收敛：快照需
去相关（每 ~0.2 ps 取样）、足够多；用拟合残差与多窗口校验。

### M1.3 DFT 验证：q\* ≈ 2k_F 吗？（(E) 通道参考）
**① 数据**：DFT —— 石墨烯费米面 / 狄拉克点几何（一次 SCF），以及（理想情况）一个温度下带电子展宽的
DFPT 色散。M1 阶段**优先用文献 DFPT/实验**做对照，自算 DFPT 推到租用阶段。
**② 方法**：解决"异常是不是电子-声子起源"。从费米面取嵌套矢量，验证 K-异常对应谷间散射 q≈K、Γ-异常
对应谷内。
**③ 算力**：(a) 自算 ~50–100 FP64 GPU-hr（半金属/狄拉克点需极密 k，~100×100+）；(b) **V100 租用**。M1
用文献则 (a)≈0。
**④ 风险**：*中*。FP64 阻塞 → M1 用文献对照即可通过 Go/No-Go；自算 DFPT 归入 M2/租用。

> **Go/No-Go 门 #1（M1 结束）**：FC-蒸馏 MLIP 能在 ≲5 GPU-hr 内重现石墨烯 K/Γ 科恩反常的扭折（与文献
> 一致），且 TDEP 跑通给出 ω(q,T)。**通过** → 进 M2/M3。**不通过**（MLIP 抹平尖点、蒸馏也救不回）→
> 这本身是干净的**负面结果**（"MLIP 漏掉科恩反常"，与 §2.1 自洽），转为以 DFT 为主、MLIP 仅做采样加速。

## M2 — q\*(T) 全温区追踪 + 2k_F 对照

**① 数据**：把 M1.2 扩到 ~8 个温度（10–600 K）；M1.3 的费米面/2k_F（一次 DFT）。
**② 方法**：解决"跳点随温怎么动"。密温区 TDEP → q\*(T) 与扭折强度随 T 的图谱；与 2k_F 嵌套对照。**关键
诚实点**：MLIP 给的是 (L) 通道；若文献/DFPT 显示 (E) 通道（电子展宽）在同温区也显著移动，必须分开标注。
**③ 算力**：(a) MLIP ~5–10 GPU-hr（8 温度 × 大胞，含 fc₃ 线宽则更多）；DFT 2k_F 见 M1.3；(b) MLIP →
**RTX 2060/H20**；DFT → **V100 租用**。
**④ 风险**：*中*。(i) (L)/(E) 难分离 → 必须配 DFT-带展宽参考，否则只能给 (L)-通道结论（仍有价值，但要
说清）。(ii) 锐异常需大胞 → 可能超 2060 显存 → 用 H20。

---

## M3 — 单层 NbSe₂：CDW / 软模随温演化（最难；Go/No-Go 门 #2）

**① 数据**：NbSe₂ 单层结构；**MLIP 对 NbSe₂ 反谐/CDW 的保真度存疑** → 很可能需 NbSe₂ 自身 DFPT
fc₂/fc₃ 做蒸馏靶（数据成本高，FP64）。实验/文献 CDW 转变温度（~33 K 块体，单层更高）作对照。
**② 方法**：解决"强反常/软模的含温稳定化"。`python-sscha` + MLIP 力 → 自由能海森矩阵 → 软模频率随 T →
CDW 失稳温度；追踪异常。SSCHA 适合接近失稳（TDEP 在此微扰基础失效）。
**③ 算力**：(a) MLIP ~10–40 GPU-hr（SSCHA 多个 population × 迭代；CDW 需 3×3 commensurate 超胞，原子数
多）；DFT 验证 ~200–500 FP64 GPU-hr；(b) MLIP → **H20**（CDW 超胞 + 系综，8 GB 2060 偏小）；DFT →
**V100/A100 租用**。
**④ 风险**：**高**。(i) 基础 MLIP 很可能抓不住 d 电子驱动的软模 → 需 DFT 蒸馏，把 M3 拖入重 FP64 区。
(ii) SSCHA 在失稳点附近收敛难、对系综大小敏感。(iii) 这是真正"e-ph 主导"的体系，MLIP 的结构性局限
（无电子通道）在此最致命 → 必须 DFT 主导，MLIP 仅加速采样。

---

## M4 — 弹道输运解读 + (L)/(E) 写作

**① 数据**：M1–M3 的 ω(q,T)、q\*(T)；电子结构（费米面；若做 EPW 则需 e-ph 矩阵元）。
**② 方法**：解决"把声子异常翻译成输运语言"。声子侧：由 ω(q,T) 群速度 → Landauer 弹道声子电导。电子侧
（**诚实**）：q\*(T) 只是**定位**费米面特征，真正的*电子*弹道窗口需 EPW（电子-声子）——声子异常是信号，
不是电导率本身。
**③ 算力**：(a) 分析 ~0（CPU-分钟）；可选 EPW +100–300 FP64 GPU-hr；(b) **CPU**；EPW → **V100/A100 租用**。
**④ 风险**：*中*。把"声子异常 ↔ 电子输运窗口"当结论而非假设 → 最大叙事风险；必须以 EPW/电子结构佐证，
否则只能报告"声子色散异常的含温图谱 + 与 2k_F 的几何吻合"，把输运联系留作受控推断。

## Go/No-Go 决策门
- **门 #1（M1 后）**：MLIP（蒸馏）能否在 ≲5 GPU-hr 重现石墨烯科恩反常？**否 → 全计划重定向**（DFT 主导
  或转负面结果），**避免在错误前提上烧掉数百 GPU-hr**。
- **门 #2（M3 前）**：NbSe₂ 软模是否需要 DFT 蒸馏才能出现？**是 → M3 预算切到 FP64 租用**（~数百 GPU-hr），
  并据此决定是否做 M3 还是换更便宜的 2D 异常体系收尾。

## 立即可做（不依赖租用、不依赖 H20）
**M0 + M1.1 + M1.2 全部能在现在唯一在线的 RTX 2060 上跑**（~3–5 GPU-hr），用文献做 M1.3 对照即可走完
**门 #1**。这是最高杠杆的一步：花 ~半天 GPU 时间，决定后面数百 GPU-hr 值不值得投。

---

### 一句话
**M0–M1 在 2060 上以 ≲5 GPU-hr 先回答"MLIP 能不能看见这个尖点"（门 #1）**；通过后，(L)-通道含温色散与
q\*(T) 追踪（M2）继续吃 MLIP 的便宜算力（2060/H20），而**所有 FP64 的电子端验证（M1.3/M3/M4）集中成一次
V100/A100 租用**——和主论文的 B 系列同一道墙。NbSe₂（M3）是最难、最可能需要 DFT 主导的部分，用**门 #2**
在投入前判定。
