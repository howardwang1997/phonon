# TD-phonon / 科恩反常项目：详细执行计划（目标 · 数据 · 方法 · 预期结果 · 算力 · 风险）

本文件是 [`TD_PHONON_ANOMALY_PLAN.zh.md`](./TD_PHONON_ANOMALY_PLAN.zh.md)（高层方案）的**可执行细化**。
每一步都给出统一的六栏：**目标 · 实验数据 · 方法论 · 预期结果 · 算力（量 + 类型）· 风险**。文末附
**风险登记表**与 **Go/No-Go 决策门**。

## 项目总目标与总体预期

- **总目标**：用 MLIP（FC-蒸馏）以**廉价算力**算出二维材料的**含温声子色散 ω(q,T)**，定位色散上的
  **斜率突变 / 跃变点（"跳点"，即科恩反常）**，追踪其随温度的移动，并检验它与电子-声子（2k_F 费米面
  嵌套）/ 弹道输运的联系。
- **总体预期结果**：得到 ≥2 个二维体系（石墨烯 + NbSe₂）的 **q\*(T) 跳点图谱**；证明（或证伪）FC-蒸馏
  能让 MLIP 重现科恩尖点；给出**含温 (L)-通道**结论，并以 DFT 厘清 MLIP 算不到的 **(E)-电子通道**。
- **核心张力**：MLIP 学的是电子基态 BO 势能面 → **(L) 晶格-非谐通道**能算且极廉价；**(E) 电子通道**
  （费米面热展宽改变科恩反常）**结构上算不了**，必须 DFT。且 §2.1 表明 MLIP 会**抹平尖点**——科恩反常
  正是尖点。**故 M1 先验证"MLIP 能否看见尖点"，是全计划的保险丝。**

## M0 — 环境与结构准备

- **目标**：工具链与结构就位，可启动 M1。
- **实验数据**：晶体结构。石墨烯（ASE `graphene` / `mp-48` 衍生 + 真空层）、单层 MoS₂（mp-2815）、
  单层 NbSe₂（C2DB / mp 衍生）。无需 DFT。
- **方法论**：2060 的 `phonon` 环境 `pip install hiphive`（TDEP 拟合）；M3 用 `python-sscha`，置于**独立
  环境**避免与 mace 的 e3nn/torch 冲突（已知 e3nn 0.4.4 vs 0.6.0 坑）。`git pull` 同步脚本。
- **预期结果**：`import hiphive/phonopy/mace` 全通过；三种结构弛豫完成；小规模 smoke-test（石墨烯单点
  力 + 一次 phonopy 色散）跑通。
- **算力**：(a) ~1–2 h；(b) **CPU + RTX 2060**（本地，无需租用）。
- **风险**：*低*。唯一坑是 hiphive/sscha 与 mace 依赖冲突 → 独立 conda 环境隔离。

## M1 — 石墨烯去风险（保险丝；Go/No-Go 门 #1）

### M1.1 谐波基线：MLIP 到底能不能看见科恩反常？
- **目标**：回答全局生死问题——FC-蒸馏 MLIP 能否重现石墨烯的科恩尖点，还是被 §2.1 软化抹平。
- **实验数据**：石墨烯结构（M0）；**参考色散用已发表的石墨烯 DFPT / 非弹性散射**（Γ-E₂g≈1600 cm⁻¹、
  K-A₁′ 的尖锐扭折，文献充分），先不自算 DFT。MLIP 用 (a) 基础 MACE-MP、(b) FC-蒸馏 MACE。
- **方法论**：phonopy 有限位移 + MLIP 力 → 沿 Γ–M–K–Γ 的密集色散；跑**异常定位器**（群速度 v=dω/dq
  不连续 / |d²ω/dq²| 峰）。对比 基础 vs 蒸馏 vs 文献，量化尖点软化幅度与蒸馏恢复能力。
- **预期结果**：基础 MACE 的扭折被**抹平/缺失**（ω 软化）；FC-蒸馏在 K（及 Γ）处**重现扭折**，与文献
  差 ≲ 数 %；定位器在 q\*=K / Γ 报出尖点。*（或得到干净负面：蒸馏也救不回 → 见门 #1。）*
- **算力**：(a) ~0.5–1 GPU-hr（石墨烯原胞 + ~5×5 超胞有限位移，几十个构型）；(b) **RTX 2060**。
- **风险**：**最高、且全局性**。(i) MLIP 抹平尖点 → 看不见异常（缓解：先蒸馏；不够则 M1.1b）。(ii) 定位
  器把数值噪声误判 → 平滑求导 + 阈值 + 多超胞收敛校验。

### M1.1b（条件触发）石墨烯 DFPT fc₂ 蒸馏靶
- **目标**：若 M1.1 蒸馏模型不够好，提供石墨烯专用蒸馏目标。
- **实验数据**：石墨烯自身 **DFPT 力常数**（"基础 fc₂"，非密 k 解析尖点 → **便宜**）。
- **方法论**：QE 中等 k 网格做石墨烯 fc₂ DFPT → 按 §2.2 蒸馏石墨烯专用 MLIP。
- **预期结果**：蒸馏 MLIP 的 fc₂ 与 DFPT 吻合，色散（含扭折）贴合 DFPT。
- **算力**：(a) ~20–50 FP64 GPU-hr；(b) **V100 租用**（2 原子但 FP64；H20 偏弱）。*可先用文献力常数绕过。*
- **风险**：*中*。FP64 阻塞；用文献 fc₂ / 公开 phonopy 数据先行。

### M1.2 Level-3 TDEP：含温色散 ω(q,T)
- **目标**：拿到 (L)-通道含温频率，跑通 TDEP 流水线。
- **实验数据**：MLIP 自产热采样快照（无外部数据）。3–4 个温度（100/300/600 K）。
- **方法论**：NVT/Langevin MD 或随机系综（MLIP 力）→ hiphive 拟合有效 fc₂(T) → ω(q,T)；定位 q\*(T)。
- **预期结果**：得到 3–4 温度的 ω(q,T)；模式随 T 软化/移动（非谐效应可见）；q\*(T) 被提取，扭折位置/
  强度随 T 有**可测量的移动**。
- **算力**：(a) ~1–2 GPU-hr（~6×6=72 或 8×8≈128 原子超胞 × ~2k 快照 × 4 T ≈ 15–20k 次力评估）；
  (b) **RTX 2060**（8 GB 容 ≲300 原子 MACE 推理）。
- **风险**：*中*。(i) 8 GB 显存：超胞过大 → 退 6×6 或 CPU 回退（慢）。(ii) TDEP 拟合收敛：快照需去相关
  （每 ~0.2 ps）、足够多；拟合残差 + 多窗口校验。

### M1.3 DFT 验证：q\* ≈ 2k_F 吗？（(E)-通道参考）
- **目标**：确认异常是电子-声子起源（q\* 对应费米面嵌套）。
- **实验数据**：DFT —— 石墨烯费米面 / 狄拉克点几何（一次 SCF），理想情况加一个温度的带电子展宽 DFPT
  色散。M1 优先用**文献 DFPT/实验**，自算 DFPT 推到租用阶段。
- **方法论**：从费米面取嵌套矢量，验证 K-异常对应谷间 q≈K、Γ-异常对应谷内。
- **预期结果**：定位到的 q\* 与 2k_F 嵌套矢量**几何吻合**（K 处谷间散射）；与文献 DFPT 一致。
- **算力**：(a) 自算 ~50–100 FP64 GPU-hr（半金属/狄拉克点需 ~100×100+ 密 k）；(b) **V100 租用**。M1 用
  文献则 (a)≈0。
- **风险**：*中*。FP64 阻塞 → M1 用文献即可过门；自算 DFPT 归入 M2/租用。

> **Go/No-Go 门 #1（M1 结束）**：FC-蒸馏 MLIP 能否在 ≲5 GPU-hr 重现石墨烯 K/Γ 科恩反常扭折（与文献
> 一致）、且 TDEP 跑通给出 ω(q,T)？**通过** → 进 M2/M3。**不通过** → 干净**负面结果**（"MLIP 漏掉科恩
> 反常"，与 §2.1 自洽），转 DFT 主导、MLIP 仅做采样加速。

## M2 — q\*(T) 全温区追踪 + 2k_F 对照

- **目标**：得到全温区的跳点图谱，并与费米面 2k_F 几何对照。
- **实验数据**：M1.2 扩到 ~8 个温度（10–600 K）；M1.3 的费米面/2k_F（一次 DFT）。
- **方法论**：密温区 TDEP → q\*(T) 与扭折强度随 T 的图谱；与 2k_F 嵌套对照。**关键诚实点**：MLIP 给的是
  (L) 通道；若文献/DFPT 显示 (E) 通道在同温区亦显著移动，必须分通道标注。
- **预期结果**：q\*(T) 与扭折强度(T) 曲线（10–600 K），趋势单调/可解释；**(L)-通道**的温度移动被定量；
  在有 DFT 处给出 (L) vs (E) 的分解。
- **算力**：(a) MLIP ~5–10 GPU-hr（8 温度 × 大胞，含 fc₃ 线宽更多）；DFT 2k_F 见 M1.3；(b) MLIP →
  **RTX 2060/H20**；DFT → **V100 租用**。
- **风险**：*中*。(i) (L)/(E) 难分离 → 须配 DFT-带展宽参考，否则只能给 (L)-通道结论（仍有价值，但要
  说清）。(ii) 锐异常需大胞 → 可能超 2060 显存 → 用 H20。

## M3 — 单层 NbSe₂：CDW / 软模随温演化（最难；Go/No-Go 门 #2）

- **目标**：拿到 NbSe₂ 软模随温的稳定化曲线与 CDW 失稳温度，并追踪强科恩反常。
- **实验数据**：NbSe₂ 单层结构；**MLIP 对 NbSe₂ 反谐/CDW 保真度存疑** → 很可能需 NbSe₂ 自身 DFPT
  fc₂/fc₃ 蒸馏靶（FP64，贵）。实验/文献 CDW 转变温度（~33 K 块体，单层更高）对照。
- **方法论**：`python-sscha` + MLIP 力 → 自由能海森矩阵 → 软模频率随 T → CDW 失稳温度；追踪异常。SSCHA
  适合接近失稳（TDEP 微扰基础在此失效）。
- **预期结果**：软模频率随 T **硬化**；提取 CDW 失稳温度并与实验比对；得到强异常的随温演化。*（或：基础
  MLIP 出不了软模 → 触发门 #2，需 DFT 蒸馏。）*
- **算力**：(a) MLIP ~10–40 GPU-hr（SSCHA 多 population × 迭代；CDW 需 3×3 commensurate 超胞，原子多）；
  DFT 验证 ~200–500 FP64 GPU-hr；(b) MLIP → **H20**（8 GB 2060 偏小）；DFT → **V100/A100 租用**。
- **风险**：**高**。(i) 基础 MLIP 很可能抓不住 d 电子驱动软模 → 需 DFT 蒸馏，拖入重 FP64。(ii) SSCHA 在
  失稳点附近收敛难、对系综大小敏感。(iii) 真正 e-ph 主导体系，MLIP 无电子通道的结构局限在此最致命。

## M4 — 弹道输运解读 + (L)/(E) 写作

- **目标**：把声子异常翻译成输运语言，并诚实界定声子侧与电子侧的可断言范围。
- **实验数据**：M1–M3 的 ω(q,T)、q\*(T)；电子结构（费米面；若做 EPW 则需 e-ph 矩阵元）。
- **方法论**：声子侧——由 ω(q,T) 群速度 → Landauer 弹道声子电导。电子侧（**诚实**）——q\*(T) 仅**定位**
  费米面特征，真正*电子*弹道窗口需 EPW；声子异常是信号，不是电导率本身。
- **预期结果**：给出弹道声子电导随 T；q\*(T) 与 2k_F 的几何吻合；**若做 EPW** 则给出电子侧弹道窗口；否则
  把输运联系作为**受控推断**报告。
- **算力**：(a) 分析 ~0（CPU-分钟）；可选 EPW +100–300 FP64 GPU-hr；(b) **CPU**；EPW → **V100/A100 租用**。
- **风险**：*中*。把"声子异常 ↔ 电子输运窗口"当结论而非假设 = 最大叙事风险 → 须 EPW/电子结构佐证，
  否则只报"含温声子异常图谱 + 与 2k_F 的几何吻合"。

## Go/No-Go 决策门
- **门 #1（M1 后）**：MLIP（蒸馏）能否在 ≲5 GPU-hr 重现石墨烯科恩反常？**否 → 全计划重定向**，避免在
  错误前提上烧掉数百 GPU-hr。
- **门 #2（M3 前）**：NbSe₂ 软模是否需 DFT 蒸馏才出现？**是 → M3 预算切到 FP64 租用**（~数百 GPU-hr），
  据此决定做 M3 还是换更便宜的 2D 异常体系收尾。

## 立即可做（不依赖租用、不依赖 H20）
**M0 + M1.1 + M1.2 全部能在现在唯一在线的 RTX 2060 上跑**（~3–5 GPU-hr），M1.3 用文献对照即可走完
**门 #1**。这是最高杠杆的一步：~半天 GPU 时间，决定后面数百 GPU-hr 值不值得投。
