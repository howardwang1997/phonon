# 周报 · 2026-07-08 — 统一 kink(T_el, T_lat) 律:找到 + 交叉验证(部署负结果,诚实)

**分支** `smearing-kink-ml` · **主题** 把支线目标重申为**一个统一 MLIP+长程模型复现科恩反常 kink 在 (E) smearing(T_el) 和 (L) 温度(T_lat) 两轴的变化**;本周找到了两轴共享的 reduced-T healing 律并交叉验证,但部署成单一模型差最后一步(机制不同)。

---

## TL;DR
- **(E) kink(T_el) via MLIP+长程项**:**已准**(上周,graphene 0.31 cm⁻¹ + 5 CDW 软模 0.011–0.16 THz;MoS₂ gapped 对照 FLAT)。
- **(L) 通道**:TiSe₂ SSCHA 落地 → crossover = **T_CDW=200K**,与 VSe₂(110K)一起**两点坐实"1T=晶格驱动 CDW"**。
- **统一 reduced-T kink 律(B2,本周头条)**:VSe₂ 的 (E)-melting 和 (L)-crossover 软模曲线,归一化后塌缩到**同一 healing 律** `f(x)=(1−x^p)^q` **(p,q)=(4.44, 3.00)**,合并 MAE 0.026;**cross-axis 预测**(在 (E) 校准预测 (L),反之)MAE **0.024–0.037** → 两轴同一形式。**真发现。**
- **诚实负结果**:把统一律当 Friedel B 幅度直接部署 → MAE 0.322(过软)→ 统一律是**软模层描述符**,不是 drop-in B 幅度律。(L) 机制是**非谐**(backbone),不是 B 衰减。
- **结论**:统一 kink 律已证 + 交叉验证;但"一个部署的 MLIP+长程模型直接输出 kink(T_el,T_lat)"**还差最后一步**(非谐 backbone + Friedel 长程项两机制共存)。

## 2. 方法

### (E) 含 smearing 谱:MLIP + 解析长程 Friedel 项
`fc₂(R;T_el) = backbone(dg0.020) + B(T_el)·exp(−κ(T_el)R)·D0(R)`,D0 = 全张量 Fermi 面波形。部署:`FriedelMACECalculator`(`scripts/smearing_kink/friedel_calc.py`)包任何 MLIP + 加谐振 Friedel 项。

### (L) 含温度谱:Path-P 非谐微调 MACE + SSCHA
Path-P 在 CDW 软模方向采双井 + 热 DFT 力 → energy-aware 微调 foundation → SSCHA(T_lat) 出自由能 Hessian 软模(T_lat)。scripts:`path_p_nbse2_make_data.py`、`vq3e_nbse2_sscha.py`。

### B2 统一 reduced-T 律分析(本周新)
归一化两轴:`x = T/T*`(T\*_el = smearing 熔点;T\*_lat = T_CDW),`y = |soft-mode|/|depth₀|`;fit 一个共享 healing 律;cross-axis 验证(在一轴校准预测另一轴)。`scripts/smearing_kink/b2_step2_crossaxis.py`。

### B1 MD-TDEP(诊断用)
`td_anharmonic.py`:MLIP-MD 多档 T → 拟有效 fc₂(T)+fc₃。本想作 (L) kink 数据源,诊断后发现不适合(见 §4)。

## 3. 结果

### 3.1 ★ 统一 reduced-T kink 律(本周头条发现)
VSe₂(唯一同时有干净 (E)+(L) 软模的):(E) T*=2368K,depth −2.18 THz;(L) T*=110K(=T_CDW),depth −12.35 THz。
**一个** healing 律 `f(x)=(1−x^p)^q` fit 合并点:**p=4.44, q=3.00**(两轴共用),combined MAE **0.026**。

| reduced-T x | (E) y | (L) y | diff |
|---|---|---|---|
| 0.5 | 0.77 | 0.90 | 0.13 |
| 0.7 | 0.50 | 0.48 | 0.02 |
| 0.9 | 0.17 | 0.15 | 0.01 |

**Cross-axis 预测**:仅在 (E) 校准 → 预测 (L) MAE **0.037**;仅在 (L) 校准 → 预测 (E) MAE **0.024**。
→ **kink(T_el) 和 kink(T_lat) 同一 healing 形式**(标度/深度不同)。`results/smearing_kink/b2_unified_law.csv`。

### 3.2 TiSe₂ SSCHA:第二个 1T 点 → origin 坐实
TiSe₂ (L)-soft-mode:20K:−552 / 100K:−340 / **200K:~0** / 300K:~0 → **crossover = T_CDW=200K**。VSe₂(110K)+ TiSe₂(200K)两点都精确在 T_CDW heal → **1T=晶格驱动 CDW 坐实**。

### 3.3 (E) 家族 + MoS₂ gapped 对照(上周收尾,本周确认)
- (E) deploy MAE:TaSe₂ 0.011 / TaS₂ 0.035 / TiSe₂ 0.034 / NbS₂ 0.071 / NbSe₂ 0.160(graphene 0.31 cm⁻¹)。
- **MoS₂ gapped 对照**:min-freq 在 4 档 degauss 全 0.000(FLAT)→ **反证 (E)-kink 是金属屏蔽驱动**(无 Fermi 面 → 无 smearing 依赖)。
- **origin-map 头图**:2H(E-response 0.58–1.83 / (L)-depth 0)→ 电子起源;1T-VSe₂(0.50 / 412)→ 晶格起源。

### 3.4 VSe₂ (E)-deploy 0.717 reframe
Naive 重蒸馏(v2,RMSE F=2.8 meV/Å)deploy MAE 0.711(≈v1,无改善)。诊断:backbone 蒸馏在熔化参考 dg0.020 → bare 软模仅 −0.101 THz,不认识深软模;deploy 分解"固定 backbone+标度 D0"假设软模本征矢不转,VSe₂ 急熔违反 → **方法边界,非 bug**(与 (L)-origin 自洽:急熔 = 类一阶)。

### 3.5 NbSe₂ EPW λ(T_el) + vetting
NQ=3:λ=17.2/116.6 @ dg0.03/0.04 → **vetted 为软模 divergence**(NQ=3 采样 CDW q=1/3,ω~2 meV → λ∝1/ω²;VSe₂=2.12 干净因 q=1/4 不在 NQ=3 网格)。NQ=4 干净 λ 重跑已排队(Box A,A2 后)。

### 3.6 ⚠️ B2 step-3 部署验证(负结果,诚实)
把统一律 `B(T)=B₀(1−(T/T\*)^p)^q` 作 FriedelCorrection 的 B_law(T_el) 部署到 VSe₂ (E):fc₂ 级 soft-mode MAE **0.322 THz**,**差于** per-material B 拟合(0.011–0.16),低温过软。
→ **统一律是软模层经验对应,不是可直接部署的 B 幅度律**。accurate (E) deploy 仍用 per-material B。

## 4. B1 诊断:MD-TDEP 抓不到 (L) crossover

B1 VSe₂ MD-TDEP 完成,anharm 诊断好(cubic-frac 0.65–0.71 = 强非谐,与晶格驱动一致),但 CDW-q 软模全程稳定 ~1.9 THz、**无 T_CDW 特征**。诊断(`_diag_vse2_md_cdw.py`):
- Path-P 模型对称点 bare 软模 = −0.131 THz(虚,但浅 ≈ −4 cm⁻¹)。
- 300K MD 从对称起跑**不塌缩**(纯热涨落)。
- 根因:**TDEP 本征给实频重整化**,给不出 SSCHA 的虚软模 crossover;叠加模型对称点不稳定浅。
→ **B2 (L) 数据源 = SSCHA fc₂(T),不用 MD-TDEP**。MD-TDEP 留给过相变 overdamped 动力学(另一问题,未做)。

## 6. 诚实边界(写文章须交代)

1. **统一律仅 VSe₂ 同时有干净 (E)+(L)**(TiSe₂ (E) 几乎不熔,−0.59→−0.465 → TiSe₂ CDW 更偏晶格驱动,本身是发现,但无法验证 (E) 侧律);n=6 偏小。
2. **统一律是软模层(q_CDW)healing,不是一般有限频 Kohn kink**;2H 无 (L) 不稳定 → 此律 **1T-only**。
3. **(L) 完整谱没做**(全 BZ ω(q,T)、linewidth、过相变 overdamped);SSCHA 只给 soft-mode crossover。
4. **"MLIP+长程微调"只验证了 (E)**;(L) 用的是 MLIP+SSCHA(无长程项),因为 (L) 物理是非谐。
5. **统一律作 B 幅度部署 = 负结果**(step-3,0.322)。
